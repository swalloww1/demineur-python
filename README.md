# demineur-python


-Fonctionnalités:

  Génération aleatoire: Placement aléatoire des mines et calcul du nombre de mines adjacentes (de 0 à 8) pour n'importe quelle dimension de grille.

  Système de Difficulté : Un menu d'accueil permettant de choisir entre 3 niveaux de jeu:

  Débutant (9x9, 10 mines)

  Intermédiaire (12x12, 20 mines)

  Expert (15x15, 40 mines)

  Gestion des Drapeaux & Compteur : Clic droit pour poser ou retirer un drapeau, avec mise à jour du compteur de mines restantes.

  Chronomètre: Suivi précis du temps(en secondes), détection de la victoire ou de défaite (avec révélation des mines cachées)

-Technique

  Langage : Python 3

  Bibliothèque graphique : Pygame

  Mathématiques: Manipulation de listes de listes, récursivité, module random
